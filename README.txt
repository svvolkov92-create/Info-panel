ИНФОРМАЦИОННАЯ ПАНЕЛЬ

Запуск: двойной клик по desktop_panel.pyw (нужен Python 3.9+).
Папка panel должна лежать рядом с desktop_panel.pyw.

Обновление с прошлой версии:
  1. Закройте панель (правый клик → Выход).
  2. Распакуйте архив в ту же папку, где лежал старый desktop_panel.pyw,
     с заменой файла. Автозапуск продолжит работать: имя и место файла те же.
  3. Запустите desktop_panel.pyw.
Задачи и настройки хранятся отдельно (%APPDATA%\DesktopPanel) и не пострадают.

Данные:
  data.json       — текущие задачи и настройки;
  data.bak.json   — предыдущее сохранение (если data.json повредится,
                    панель сама восстановится из него и сообщит об этом);
  error.log       — журнал ошибок.

Тесты (из этой папки, в командной строке):
  python run_tests.py         модульные тесты, секунда
  python run_tests.py --gui   ещё и сценарии интерфейса (нужен экран от 1900 px в высоту)
  python tests/benchmark.py   замер скорости на трёх объёмах данных (--profile — с профилем)

Устройство кода (папка panel):
  core.py           константы, разбор ввода, даты, повторы, хранение, звук, вызовы Windows
  app.py            класс Panel: сборка окна, главный цикл, запуск
  tasks.py          список задач: отрисовка, правка, перетаскивание, клавиши, отмена
  planning.py       цели, будущие задачи, неделя, матрица, поиск, обзор недели, шаблоны
  calendar_view.py  календарь
  pomodoro.py       помодоро, режим фокуса, звуки
  blocks.py         заметки, итоги, события, порядок и высота блоков
  window.py         меню, трей, сквозные клики, размер и положение окна
  settings.py       окно настроек
  windows.py        отдельные окна (карточка, неделя, матрица, поиск, обзор)
  widgets.py, tray.py  прокручиваемая область, значок в трее

СБОРКА УСТАНОВЩИКА (.exe)
Вариант 1, на своём компьютере: поставьте Inno Setup 6 (jrsoftware.org/isdl.php)
и запустите build.bat. Готовый установщик: dist\DesktopPanelSetup-1.0.0.exe.
Версию можно передать: build.bat 1.2.0
Вариант 2, GitHub: при каждом push в main установщик собирается сам
(вкладка Actions → последний запуск → Artifacts). Тег вида v1.2.0 создаёт
страницу Releases с установщиком.
Данные в %APPDATA%\DesktopPanel при установке, обновлении и удалении не трогаются.
